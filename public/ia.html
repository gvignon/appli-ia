Cours vers LaTeX — génération IA directe

Dépose un cours (PowerPoint, Word ou PDF) : l'IA rédige directement un document LaTeX complet, restructuré, avec les formules en vraies mathématiques et les schémas décrits en texte — sur le modèle d'un cours de référence relu et validé.

À savoir avant de lancer

  • Mode conseillé pour les cours avec des formules mathématiques, ou pour obtenir un document réorganisé comme un polycopié.
  • Pour un cours surtout textuel, le mode avec relecture garde le texte d'origine et vous laisse corriger chaque description de schéma.
  • L'IA reformule le cours : relisez le résultat avant de le transmettre, en particulier les formules (celles qui sont douteuses sont signalées « formule à vérifier »).
  • Comptez environ 3 minutes pour 60 diapositives : laissez la page ouverte.
